## D-068 (2026-10-16): numbered sound pools the player can extend and optional commercials (owner rule 0.14; the clone, nothing in the original changes)

Owner request in chat: "Jim's games have sound files that are numbered, such as foot0, foot1, foot2. I want the user of all my games to be able to add more sounds if they wish, especially for comments in various sports games, and for optional commercials." Written as AGENTS.md rule 0.14 and playbook 7.7.1 first, then applied to nfl4 in the same day. Decisions made automatically (rule 0.8):
1. Which names are pools: decided from the code, not the names (WAV_EVENT_MAP 8). Two pools: `ambient` (foot8 to foot10, PlayRan's `Int(Rnd * 3)`) and `celebration` (foot15 to foot24, `Int(Rnd * 10)`). Every other foot<N> is a different sound for a different event. The game's commentary is text (banter), so "comments" are covered by banter.txt with `[sound file]` (L12), and no numbered commentary wav exists to extend.
2. Names of added files: the pool's plain-word name plus a number (`celebration3.wav`), because all 26 originals share the base `foot` and a number alone says nothing about the event. Scanned from the folder listing (never probed), case-insensitive, wav, ogg, flac or mp3, number order, gaps allowed, no cap; two files with one number: the first by name is used, the other is logged.
3. The draw: `Int(Rnd * member count)` in the same place as the original's draw, so with nothing added every draw, the golden transcript and the conformance tests are unchanged (`test_pag_golden.py` passes unchanged; `tests\test_sound_pools.py` proves the draw sizes). A rule 0.14 change of behavior, recorded: an original member switched off in sounds.txt now LEAVES the draw (before, it stayed and played silence, G-A3); the one test that said so (`test_a_waited_sound_switched_off_takes_no_time...`) keeps G-A3 for the waited sounds and the pool case moved to the new test file. An original member with no usable file at all stays in (a broken install must not move the draws). An added file that cannot be read is left out and logged; one spoken notice per start (G-A6).
4. Levels of an added member (the original has no rule for a new file): celebration -300 + wavol with the original's pitch draw around the file's own rate; ambient -1200 + wavol (foot9's), centered. Wrong if the owner finds added ambient sounds too loud or too quiet at the playtest (P8 S8.2): then change one constant (`ADDED_AMBIENT_LEVEL`).
5. Commercials: four breaks (quarter, two-minute-warning, halftime, final), where each sits is in CUSTOMIZABLE_CONTENT 15. Nothing ships; setting off by default (also with files); every, second, third; spoken cue "Commercial. Any key skips it."; the key that skips is swallowed; own random generator (a shuffle bag), nothing in saves, log or scores; the sound layer's volume wavol applies. Break order and "final" after the player's key: after the final score the original waits for a key, so the commercial follows it. Wrong if the owner finds the final break awkward (then move it after the statistics: one line in `pag_breaks.game_end`).
6.
