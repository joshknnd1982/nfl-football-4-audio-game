### 9.1 The six speakers (Q-021 answered, P3 S3.1) [CODE (lifted)]
Every speaker takes one text argument. "Voice load" means: when the wanted voice number differs from LastVoice, `Set Voice = Nothing`, `Set Voice = New SpVoice`, select that voice token from `GetVoices`, Rate = vr, Volume = the volume of that role, LastVoice = the number. | speaker | voice and volume | waits until spoken | log | replay list |
|---|---|---|---|---|
| say | announcer anv, volume 1 | yes (flags 0) | yes | no |
| say2 | announcer anv, volume 1 | no (flags 1, asynchronous) | yes | yes |
| say3 | qorp = 1: quarterback voice of side wisoff, volume 2 x wisoff; else punter voice of side wisoff, volume 2 x wisoff + 1; speaks " " first on a voice change | yes | no | no |
| say4 | announcer anv, volume 1 | yes | yes | yes |
| say5 | announcer anv, volume 1 | no | yes | no |

- Game: one speech layer with these six calls; the starter kit's speak() and its wait for the end of speech (7.4.4) implement "waits until spoken"; the log and the replay list are kept (the log file only when the original writes it).
- Voice cache (S3.2, CODE): `LastVoice` holds a voice NUMBER. say, say2, say4, say5 and inrep reload the voice (Set Voice = New SpVoice, select the token, Rate = vr, Volume = the role's volume) only when the wanted number differs from LastVoice; say3 does the same with the number of the quarterback or punter voice.
