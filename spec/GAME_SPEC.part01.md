## 1. Overview
A turn-based, audio-only American football simulation for blind players. The player chooses five SAPI voices (announcer, own quarterback, opponent quarterback, own punter, opponent punter), types a coach name, picks a team for a 16-game season (NFL teams arranged in AFC and NFC divisions named in the strings: A. F. C. West, East, North and N. F. C. South among them; the exact count and list come from the strings in P2: 32 team nicknames, verified in P2: section 11), plays the game with the keyboard (running plays, line plunge, passes, screen pass, blitz, kick off, punt, field goal, extra point or two-point conversion, safety), then play-offs and a Super Bowl. Quarters have 25 to 35 plays; a two-minute warning comes before the end of the second and fourth quarter; about five plays follow it. Announcer commentary and jokes are spoken. [Source: football.txt and the exe's help strings; OBSERVED from text.] The code (S3.4, section 5.6) draws 30 to 37 plays per quarter and 5 to 7 plays after the two-minute warning, and plays the game as sections 4.14 to 5.12 describe; where the readme and the code differ, the code wins (D-027). [CODE (lifted)]
Special keys named in the program strings: F5 special key instructions, F6 game instructions, F7 football terminology and hints, F8 comments toggle, F11 adjust volume of voices and sounds, F12 change voice, Ctrl adjust rate of speech. [OBSERVED from strings; the exact behavior of all seven is section 4.2 to 4.8, CODE (lifted), P3 S3.2.]
